The Sunmeld test build now opens with a short tutorial. Sunmeld is still in development for iOS and Android.

## Learn it on the first game

The tutorial walks you through the first game instead of putting the rules on a separate page. You learn to drop a stone, to merge two of the same stage, and what happens when the tub overflows, while you are playing.

## Short on purpose

A merge duel is easy to understand once you have seen one merge. We kept the tutorial short so that most of the first game is just a game.

## Help for special stones

Special stones now come with an in-game explanation too, so you can read what a stone does before you rely on it.

## What is next

We will keep watching where new players hesitate and adjust the tutorial. There is no release date yet. See the [release notes](/releases/) for test build changes.

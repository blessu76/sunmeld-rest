Sunmeld is still in development for iOS and Android. This note is about a mode where you play by yourself.

## Why a solo mode

Sunmeld is built around turns against AI opponents. Some players wanted a quieter game: no rival, no turns, only their own stack and one run to see how far it goes. So we added a solo mode, called stacking alone, and kept it inside Sunmeld instead of making a separate app.

## The same stones, a different match

Solo mode uses the same falling and merging physics as the main game. What is new is the match itself. There is no opponent and no turn order. Chains add more to the score, and a merge at the sun stage gives a bonus. A stone behaves the same way in both modes.

## Keeping records

Your solo runs are saved on the phone and copied to iCloud, the same way your progress is kept for the main game.

## How it is unlocked

Trying solo mode is free for a few runs. After that it is covered by the one purchase the game already has. There are no ads and no separate product to buy.

## Balance

We ran simulated runs, some with random drops and some with a simple greedy strategy, to check that a run does not end too fast or never end. We found no extremes, so the values stayed as they were. Feel on a real phone still needs more play time.

## What is next

We will tune the feel once more people have played it on real phones. There is no release date yet.

## FAQ

### Does solo mode replace the main game?

No. It is another way to play with the same stones. The main game with AI opponents is unchanged.

### Does solo mode use the same rules?

The falling and merging physics are the same. The match itself has no opponent and no turns.

### Is there an extra purchase for solo mode?

No. It is covered by the one purchase the game already has.

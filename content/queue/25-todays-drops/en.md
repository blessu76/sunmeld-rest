Tap “Today” on the home screen of the Sunmeld test build to open “Today’s drops,” a solo stacking round. Your device’s date sets the order of the stones. The game is still in development for iOS and Android.

## The same order on the same date

Start again on the same date and the stones come in the same order. Try grouping the opening stones on one side, then spreading them across the jar on another attempt. The order stays the same, but where you place them changes which merges you can set up next.

## The result keeps the start date

Finish after midnight and the result still shows the date you started. Your best score goes in that day’s record. Choose “Copy result” to copy text with the date and score, ready to paste wherever you like.

## FAQ

### Is this the same as the Daily Challenge against the AI?

“Today’s drops” is a solo stacking round with no opponent.

### What stones will I get if I start again that day?

Rounds started on the same date give you stones in the same order.

### Which day gets the score if I finish after midnight?

The score counts toward the day you started the round.

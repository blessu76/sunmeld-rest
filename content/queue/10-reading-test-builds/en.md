Sunmeld is not released yet, but the [release notes](/releases/) page already has entries. This note explains what they are.

## A test build is not a release

Each entry is a test build for the iOS beta. It is how we try changes with testers while the game is still in development. The Android version is being built too, and it has no test builds here yet.

## One note per build

Every build gets its own note with a short list of what changed, for example the daily challenge, customization or stability work. We write the note before the build goes out, so the page and the build stay in step.

## What the notes leave out

The notes describe changes you can see in the game. They do not promise a date and they do not list prices. If something is still being tested, such as the purchase flow, the note says so.

## Reading them in order

If you read the entries from the oldest to the newest, you can follow the game growing: League 1 and the star rule first, then the alternating first move, then the daily challenge. Each journal post here goes a little deeper into one of those changes.

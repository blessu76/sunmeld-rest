The Sunmeld test build has a daily challenge. Sunmeld is still in development for iOS and Android.

## One game a day

Each day there is one new game, and it is the same for everyone that day. A card on the home screen shows whether you have played it yet.

## Streak and stars

Your streak and the stars you earn are saved. Playing the day's game keeps the streak going, and a better result earns more stars, like in a league.

## Why a daily game

The league is for learning opponents. The daily challenge is a quick game to come back to, and a fair way to compare a result with a friend who played the same one.

## What is next

We will see how testers use it before changing anything. There is no release date yet. See the [release notes](/releases/) for test build changes.
